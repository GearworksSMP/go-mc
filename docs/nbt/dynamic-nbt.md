# Dynamic NBT

This is an alternative style of NBT library that allows you to dynamically add, remove, and query data without having to predefine data types or manipulate annoying `map[string]any`!

How to use it? See [![Go Reference](https://pkg.go.dev/badge/github.com/Tnze/go-mc/nbt/dynbt.svg)](https://pkg.go.dev/github.com/Tnze/go-mc/nbt/dynbt)
